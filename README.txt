ДЕН ГРАЧОВ — ЛІТЕРАТУРНИЙ САЙТ

Відкрийте index.html у браузері, щоб побачити сайт.

Публікація: завантажте всю папку (index.html і assets/) на статичний хостинг, наприклад Netlify або GitHub Pages. Для появи в Google потрібні публічна адреса, індексація та час.

Перед публікацією:
1. Узгодьте з автором назву першого вірша та текст рукопису.
2. Додайте перевірену біографію й контактну адресу.
3. Додавайте нові вірші з реальними датами публікації (не вигадуйте попередні дати).
4. Для англійських перекладів потрібен окремий переклад, а не автоматичне перемикання оригінального вірша.

Це початкова версія сайту; вона ще не розміщена в інтернеті.
